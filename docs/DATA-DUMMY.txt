REKAP DATA DUMMY (CONTOH) — kerja-harian.id
========================================================================

Ringkasan
---------
- 100 lowongan contoh, SEMUA SUDAH KEDALUWARSA (tanggal kerja 3 Jul 2026 s.d. 28 Sep 2026).
- Status lowongan: 'tutup' -> tidak bisa dilamar. Tampil di halaman Cari Kerja pada bagian
  "Kerjaan yang sudah lewat" dengan label "Sudah lewat".
- 18 akun pemberi kerja contoh:
    * TANPA nomor HP (kolom phone kosong) -> nomor tidak pernah tampil di mana pun.
    * Email pengganti @contoh.invalid (tidak bisa menerima email).
    * Kata sandi tidak valid -> akun TIDAK BISA dipakai masuk.
- Semua ditandai kolom is_dummy = 1 (tabel users dan jobs); lowongan juga punya kode
  dummy_key DUMMY-001 s.d. DUMMY-100.
- Dimasukkan otomatis SEKALI saat aplikasi pertama jalan (penanda: app_meta.key = 'dummy_jobs_v1').
  Jika dihapus, data ini TIDAK akan dimasukkan lagi.
- Untuk mematikan sebelum terlanjur masuk: set env SEED_DUMMY_JOBS=0 di Vercel lalu Redeploy.
- Sumber data: src/lib/dummy-jobs.json

Cara menghapus semua data dummy
-------------------------------
Turso dashboard -> database kerjaharian -> Edit Data / SQL Console (atau: turso db shell kerjaharian),
lalu jalankan:

  DELETE FROM jobs  WHERE is_dummy = 1;
  DELETE FROM users WHERE is_dummy = 1;

Cek sisa data dummy:  SELECT COUNT(*) FROM jobs WHERE is_dummy = 1;
